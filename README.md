# ModuleGraphRules

**The half of your module graph that `Package.swift` has no vocabulary for.**

`Package.swift` describes what a target *depends on*. It has no way to express what a target is *forbidden* from depending on — and that second half is the one that decays once more than a handful of people are opening pull requests.

`ModuleGraphRules` is a small, dependency-free Swift library that makes the policy data:

- **Layer ranks** — a module may import downward, and sideways only in bands that allow it.
- **Named denied edges** — for the imports that are legal by rank and forbidden anyway, with a reason a reviewer will actually read.
- **Cycle detection** — iterative DFS, no recursion, deterministic output.
- **Blast radius** — if I touch this module, how many modules have to rebuild? This is the number that predicts your CI bill, and it is a property of your graph, not of your build tool.

## The rules are data

```swift
public static let standard = RuleSet(
    layers: [
        Layer(name: "Foundation", rank: 0, allowsSiblingImports: true),
        Layer(name: "Platform",   rank: 1, allowsSiblingImports: true),
        Layer(name: "Domain",     rank: 2, allowsSiblingImports: true),
        Layer(name: "Feature",    rank: 3, allowsSiblingImports: false),
        Layer(name: "App",        rank: 4, allowsSiblingImports: false)
    ],
    deniedEdges: [
        DeniedEdge(
            from: "PaymentsFeature",
            to: "AnalyticsCore",
            reason: "Payments may not emit analytics directly — route through PaymentsDomain."
        )
    ]
)
```

## Auditing a graph

```swift
let audit = GraphAudit.asShipped

audit.failsBuild                       // true
audit.errorCount                       // 4
audit.warningCount                     // 1
audit.blastRadius.entry(for: "SessionDomain")?.rebuildCount   // 12 of 16

for violation in audit.violations {
    print("[\(violation.severity.label)] \(violation.ruleName): \(violation.message)")
}
```

Output against the bundled sixteen-module sample graph — real messages, column-aligned here for width:

```text
[error]   denied-edge        PaymentsFeature → AnalyticsCore is denied. Payments may not
                             emit analytics directly — route through PaymentsDomain.
[error]   dependency-cycle   Dependency cycle: AccountDomain → NetworkingCore →
                             SessionDomain → AccountDomain
[error]   dependency-cycle   Dependency cycle: NetworkingCore → SessionDomain →
                             NetworkingCore
[error]   layer-inversion    NetworkingCore (Foundation) imports SessionDomain (Domain) —
                             that points up the stack.
[warning] sibling-import     CheckoutFeature imports its Feature sibling CatalogFeature;
                             that band forbids sideways imports.
```

## What fixing four edges buys you

`SampleGraphs.remediated` is the same sixteen modules with three of those edges deleted and the fourth repointed one layer down — no module added, none removed.

| | As shipped | After |
|---|---|---|
| Import edges | 39 | 36 |
| Errors / warnings | 4 / 1 | 0 / 0 |
| Mean rebuild share | 40% | 34% |
| `SessionDomain` blast radius | 12 of 16 | 6 of 16 |
| `AccountDomain` blast radius | 12 of 16 | 8 of 16 |

## How to run it

```bash
git clone https://github.com/rajatslakhina/spm-build-system-ceiling-article-demo.git
cd spm-build-system-ceiling-article-demo
swift build && swift test          # the library
open Demo/Demo.xcodeproj           # the app — pick any Simulator, Build & Run
```

`Demo.xcodeproj` consumes the library through a local package reference (`relativePath = ..`), so there is nothing else to fetch and no second repository to clone. The app target is a thin shell; the whole UI lives in the library's `RuleGuardDemoView`, which is the shape you want in a real modular app.

## Verification status

Honest accounting of what was and was not verified when this repository was published:

- ✅ `swift build` — clean, Swift 6.0.3 toolchain, zero warnings.
- ✅ `swift test` — **21 tests, 0 failures**, covering every rule, cycle detection (including rotation-invariant deduplication and termination on cyclic graphs), blast-radius reverse reachability, and the edge cases: empty graph, unknown module, self-import, duplicate module names, unknown layer.
- ✅ `Demo.xcodeproj/project.pbxproj` — hand-authored and structurally validated: balanced braces and parentheses, 18 object identifiers defined, zero dangling references, zero unused definitions. Shared scheme committed so it is selectable on a fresh clone.
- ❌ **Not run on the iOS Simulator, and there are no Simulator screenshots.** This repository was generated by an unattended scheduled task, and macOS UI automation requires an interactive approval that cannot be granted during a scheduled run. Rather than fake a screenshot or imply a run that did not happen, this is recorded as a gap. The SwiftUI layer (`RuleGuardDemoView`) compiles as part of the library on every `swift build`, but it has not been rendered on a device.

If you clone this and the app does something unexpected on first run, that gap is why — open an issue and I'll fix it.

## Layout

```
Package.swift                             library product only — no executable target
Sources/ModuleGraphRules/
  GraphModels.swift                       ModuleID, Layer, Module, ModuleGraph
  RuleSet.swift                           the policy, including RuleSet.standard
  Violation.swift                         Severity, Violation.Kind, rule names
  GraphValidator.swift                    rule checks + iterative cycle detection
  BlastRadius.swift                       reverse reachability, per-module rebuild counts
  SampleGraphs.swift                      the 16-module before/after graphs, GraphAudit
  RuleGuardDemoView.swift                 the SwiftUI demo UI
Tests/ModuleGraphRulesTests/              21 tests
Demo/Demo.xcodeproj                       runnable iOS app, local package reference
Demo/DemoApp.swift                        @main App shell
article-assets/                           original diagrams used in the article
```

Requires Swift 6.0+, iOS 17+ / macOS 14+. No third-party dependencies.
